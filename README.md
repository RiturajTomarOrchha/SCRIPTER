# Scripter — Complete Content Creation

Scripter is a responsive, mobile-first web platform for complete content creation—guiding creators and professionals from idea discovery and research through scriptwriting, teleprompter recording, and video production.

View your app in AI Studio: https://ai.studio/apps/cc6afc0f-b5c6-4517-b678-179a618cee75

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```
2. Set the `GEMINI_API_KEY` in `.env.local` to your Gemini API key (optional for UI exploration):
   ```bash
   VITE_GEMINI_API_KEY=your_key_here
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
